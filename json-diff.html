Free JSON Diff Tool Online

Compare two JSON documents structurally and find added keys, removed keys, changed values, nested differences, array index changes, and type changes.

How to Use

Paste or upload JSON on both sides, click Compare, then review added, removed, changed, and type-changed paths.

Example

The example compares `age`, `address.city`, a new `active` key, and an array item by index.

Privacy Note

Your JSON is processed locally in your browser and is not uploaded to a server.

Limitations

  • Arrays are compared by index.
  • Very large JSON files may be limited by browser memory.

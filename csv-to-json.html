How Nested JSON Works

CSV is flat, so nested JSON is created from column names. Use dot notation in headers to describe object paths. For example, `address.city` becomes an `address` object with a `city` field, while headers without dots stay at the top level.

Nested CSV

name,address.city,address.zip,contact.email
Alice,Denver,80110,alice@example.com

Nested JSON

[
  {
    "name": "Alice",
    "address": {
      "city": "Denver",
      "zip": 80110
    },
    "contact": {
      "email": "alice@example.com"
    }
  }
]

Limitations

  • CSV is naturally flat.
  • Nested JSON is created using dot notation in headers.
  • Arrays are not supported in MVP.
  • Very large files may be limited by browser memory.

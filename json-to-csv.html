How Nested JSON Becomes CSV

CSV columns are flat, so nested object paths become dot notation headers. For example, `address.city` stores the `city` value inside the `address` object, and arrays are stored as JSON strings in CSV cells.

Nested JSON

[
  {
    "name": "Alice",
    "address": {
      "city": "Denver",
      "zip": 80110
    },
    "contact": {
      "email": "alice@example.com"
    }
  }
]

CSV

name,address.city,address.zip,contact.email
Alice,Denver,80110,alice@example.com

Limitations

  • JSON can be deeply nested while CSV is flat.
  • Nested objects are flattened using dot notation.
  • Arrays are stored as JSON strings in CSV cells.
  • Very large files may be limited by browser memory.

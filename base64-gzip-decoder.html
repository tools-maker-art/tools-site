Base64 + Gzip Decoder

Paste a Base64 string that contains gzipped text. The tool decodes, decompresses, detects the output format, and lets you copy or download the result.

How to Use

  1. Paste gzipped Base64 text.
  2. Select decode and detect.
  3. Copy the output or download it using the detected extension.

Example Input

Use the example button to load a small gzipped JSON-style payload and see auto-detection in action.

Privacy Note

Your data is processed locally in your browser and is not uploaded to a server. No pasted content is logged or sent anywhere.
